# Moodle-Vollfassung

Die vollständige Moodle-Seite **Mission Space – Mission 01 bis 13** wird als HTML-Fragment direkt in den Moodle-Editor eingefügt.

Für die aktuelle Fassung gelten folgende feste Webserver-Pfade:

- Schülerdownloads: `https://moodle.harzenetter.eu/mission-space/downloads/...`
- gemeinsame Datei: `https://moodle.harzenetter.eu/mission-space/downloads/shared/SpaceWindow.java`
- Space-Icons: weiterhin `https://www.harzenetter.eu/moodle/src/...`

Dadurch müssen UML-/Java-ZIP-Dateien und Icons nicht zusätzlich in Moodle hochgeladen werden.

Die frühere Datei `Mission_Space_Moodle_Vollfassung_webserver_v2.zip` wurde entfernt, weil sie noch zum alten Deployment-Aufbau gehörte. Maßgeblich ist die aktuelle Moodle-HTML-Fassung mit den oben genannten URLs.
